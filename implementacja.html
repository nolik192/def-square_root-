Implementacja

Metoda babilońska w pseudokodzie, Pythonie, C++ i arkuszu kalkulacyjnym.

Pseudokod

FUNKCJA pierwiastek(S)
    JEŻELI S < 0 WTEDY BŁĄD
    JEŻELI S = 0 WTEDY ZWRÓĆ 0
    eps ← 10⁻¹⁵
    x ← S                              // przybliżenie początkowe
    POWTARZAJ
        x_nowe ← (x + S / x) / 2
        JEŻELI |x − x_nowe| ≤ eps · x_nowe WTEDY ZWRÓĆ x_nowe
        x ← x_nowe
    KONIEC

Python

Python – przykład

import math

EPS = 1e-15  # dokładność (błąd względny)


def sqrt_babylonian(s, eps=EPS):
    """Pierwiastek kwadratowy z s metodą babilońską."""
    if s < 0:
        raise ValueError("liczba ujemna")
    if s == 0:
        return 0.0
    x = float(s)                       # przybliżenie początkowe x0 = S
    while True:
        x_next = 0.5 * (x + s / x)     # średnia z x i S/x
        if abs(x - x_next) <= eps * x_next:
            return x_next
        x = x_next


for s in (2, 10, 12345, 1000000):
    print(f"S = {s}")
    print(f"  metoda babilońska: {sqrt_babylonian(s):.15f}")
    print(f"  math.sqrt():       {math.sqrt(s):.15f}")

C++

babilonska.cpp

#include <cmath>
#include <cstdio>
#include <initializer_list>

const double EPS = 1e-15;  // dokładność (błąd względny)

double sqrt_babylonian(double s) {
    if (s <= 0) return 0.0;
    double x = s;                          // przybliżenie początkowe x0 = S
    while (true) {
        double x_next = 0.5 * (x + s / x); // średnia z x i S/x
        if (std::fabs(x - x_next) <= EPS * x_next) return x_next;
        x = x_next;
    }
}

int main() {
    for (double s : {2.0, 10.0, 12345.0, 1000000.0}) {
        std::printf("S = %.0f\n", s);
        std::printf("  metoda babilonska: %.15f\n", sqrt_babylonian(s));
        std::printf("  std::sqrt():       %.15f\n", std::sqrt(s));
    }
}

Kompilacja: g++ -O2 -std=c++17 babilonska.cpp -o babilonska. Program wypisuje te same liczby co wersja w Pythonie, bo oba języki używają tego samego typu double.

Arkusz kalkulacyjny

W arkuszu każdy wiersz to jedna iteracja, a formuła odwołuje się do komórki powyżej. Gotowy plik: metoda_babilonska.xlsx – po zmianie liczby w komórce B3 cała tabela przelicza się automatycznie.

  1. B3 – liczba S; B4 – przybliżenie początkowe =B3; B5 – dokładność 1E-15.
  2. A9 = 0, B9 = =B4.
  3. B10 = =(B9+$B$3/B9)/2 – wzór metody (znak $ blokuje odwołanie do S).
  4. E10 = =MODUŁ.LICZBY(B10-B9) – zmiana przybliżenia.
  5. G10 = =JEŻELI(E10<=$B$5*B10;"tak";"nie") – czy spełniono warunek zakończenia.
  6. Wiersz 10 kopiujemy w dół; liczby formatujemy z 15 miejscami po przecinku.
